# obsidian-skills

## OVERVIEW
Obsidian note-taking skills.

## SKILLS (3)
| Skill | Description |
|-------|-------------|
| `canvas-atlas` | Source-backed architecture maps with single and nested Canvas modes |
| `to-note` | Save content as a note in any Obsidian vault, found by its `.obsidian` folder |
| `vault-moc` | Build or refresh MOC index notes from existing notes and real wikilink evidence |

## CONVENTIONS
- Skills here are user-facing helpers; behavior lives in Markdown. `canvas-atlas` ships a read-only Python validator with tests and example canvases; the others stay Markdown-first.
